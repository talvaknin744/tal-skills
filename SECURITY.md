# Security Policy

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/talvaknin744/tal-skills/security/advisories/new). Include the affected component, impact, and a minimal reproduction when possible. Do not include secrets or personal data in a public issue. For non-sensitive security questions, use a GitHub issue.

This repository has no published support window or guaranteed response time. Acknowledgment and remediation depend on maintainer availability.
