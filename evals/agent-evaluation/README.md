# Agent evaluation inputs

Two relevant reviews and one ordinary software testing nontrigger are authored
inputs, not behavioral results. Follow the [evaluation guide](../README.md).
Supply only the selected prompt, raw fixture and normally discoverable candidate
to the responder. Keep this guide and the private scoring corpus outside the
trial workspace.

The first review catches reported completion with missing authoritative effects.
The comparison review covers biased grading, unknown outcome evidence, clean
trial isolation, repeatability, preserved regressions and measured cost. Its
synthetic retained results are fixture inputs, not runs of this new skill.

All cases permit local inspection and require unchanged fixture files. Native
host trials and independent scores must be recorded separately with exact frozen
candidate identities. A corpus integrity pass proves no agent behavior.
