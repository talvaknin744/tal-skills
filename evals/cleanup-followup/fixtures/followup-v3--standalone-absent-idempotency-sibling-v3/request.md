An asyncio HTTP handler owns an export task and a connection from an async pool. Pool release is an async cleanup operation. The remote service may commit send_batch before the client receives its response. Each batch has a stable accepted batch_id. At 11:00 the HTTP caller disconnects while awaiting a response. The handler returns an empty success list; the export task later reports a connection already returned to the pool. Cancellation should reach owned work and release its connection after that work stops. Already committed batches must not be sent as a new business operation.
