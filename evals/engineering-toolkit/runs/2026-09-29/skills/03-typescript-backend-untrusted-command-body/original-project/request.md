The server authenticates callers before invoking this handler. req.auth.tenant is trusted; req.body is arbitrary parsed JSON. A valid charge is an object with a positive integer amountCents <= 100000, a nonempty requestId up to 80 characters, and no caller-controlled tenant selection. The ledger is a side-effecting API and performs no input validation. Request amount -20 from tenant blue was accepted; a body claiming tenant red also reached the ledger. Valid requests must preserve their public result shape.
