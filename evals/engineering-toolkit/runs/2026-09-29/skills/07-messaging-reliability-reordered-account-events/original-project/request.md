Events contain complete account snapshots, not deltas. account_id scopes revision, which only increases for an account. event_id identifies one publication. Delivery is at least once and can reorder. History: e12(account=a, revision=12, tier=gold); e12 again; e11(account=a, revision=11, tier=silver). Every newly applied snapshot emits one audit effect. Store and audit are in the same local database transaction. A malformed event must not retry forever. No producer ordering change is available.
