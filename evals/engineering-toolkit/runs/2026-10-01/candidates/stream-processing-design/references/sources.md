# Sources and evidence limits

The workflow, contract fields, identity/correction composition, and verification schedules are independently authored synthesis. They are not copied vendor procedures. The package's general result contract is broader than any one product's feature guarantees. Historical articles explain mechanisms; installed versions and current official documentation govern implementation.

- [Estuary: A decade of Gazette](https://estuary.dev/blog/gazette-streaming-broker-architecture/), 2026-09-17, and [Gazette broker concepts](https://gazette.readthedocs.io/en/latest/brokers-concepts.html): replicated hot appends and immutable historical fragments share offsets. A journal remains bounded by its primary and replicas; more journals are needed for write partitioning.
- [Materialize: Replica expiration](https://materialize.com/blog/replica-expiration/), 2025-01-15: temporal filters retain scheduled additions/retractions beyond visible rows. Historical eligibility and measured memory savings are not universal current guarantees. [Current temporal-filter documentation](https://materialize.com/docs/transform-data/patterns/temporal-filters/) describes late-event and materialization restrictions. [EXECUTE UNIT TEST](https://materialize.com/docs/sql/execute-unit-test/) can test result sets at a selected logical time; it does not prove subscription history or a memory bound.
- [RisingWave: Trigger mechanism](https://risingwave.com/blog/deep-dive-into-the-risingwave-stream-processing-engine-part-3-trigger-mechanism/), 2023-11-24, explains barriers and watermarks. [Current watermarks](https://docs.risingwave.com/processing/watermarks) and [emit-on-window-close](https://docs.risingwave.com/processing/emit-on-window-close) govern lateness/output policy. Table watermark TTL can ignore expired changes without retracting earlier downstream results. The article's old experimental label is not a current status claim.
- [Decodable: Real Time Streaming Joins With SQL](https://www.decodable.co/blog/real-time-joins-with-decodable), 2022-10-14, motivates maintained enrichment. [Join overview](https://docs.decodable.co/pipelines/joins.html), [regular joins](https://docs.decodable.co/pipelines/joins/regular-joins.html), and [temporal joins](https://docs.decodable.co/pipelines/joins/temporal-joins.html) distinguish retained state, provisional outer-join nulls, historical lookup, and latest-value lookup. Documentation's output-type descriptions are not fully consistent; inspect the deployed plan and sink contract.
- Apache Flink v2.3.0 [deduplication](https://nightlies.apache.org/flink/flink-docs-stable/docs/sql/reference/queries/deduplication/) removes duplicates over chosen columns using first/last time ordering. That SQL rule does not decide logical identity, conflicting payload authority, or complete replacement versus required delta. [SELECT DISTINCT](https://nightlies.apache.org/flink/flink-docs-stable/docs/sql/reference/queries/select-distinct/) notes that state can grow indefinitely and TTL can affect correctness.

Documentation checked 2026-10-01; most product links are unversioned. Article prose and captions were read; image pixels and sample environments were not executed. The skill makes no product-independent exactly-once, automatic finality, or state-size guarantee.
