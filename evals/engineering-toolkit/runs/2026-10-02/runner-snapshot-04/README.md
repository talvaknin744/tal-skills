# Repair freezes 04–06

This directory preserves both regression and integration repair freezes 04, 05 and 06 as exact byte copies, with the unchanged runner and dependency files from runner-snapshot-03. [snapshot.json](snapshot.json) records source content hashes, file modes, freeze digests and candidate versions. Staging provenance uses filenames rather than local absolute paths.

These are intermediate evidence snapshots. They preserve candidates associated with partial results and do not indicate approval or replace any historical score. Candidate bodies, model responses, private reasoning and authentication data are not included.
