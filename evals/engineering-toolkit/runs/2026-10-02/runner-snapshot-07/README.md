# Repair freezes 09 and 10

This directory retains the integration and regression freeze09 and freeze10 files
as exact byte copies, with the unchanged runner and dependency files from
[runner-snapshot-06](../runner-snapshot-06/snapshot.json).
[Snapshot metadata](snapshot.json) records hashes, modes, candidate identities and
checks against the unchanged raw cases, prompts, rubrics and fixtures.

Freeze09 is an intermediate merge-control revision. Freeze10 records the later
report-control revision separately. Neither snapshot replaces an earlier result
or grants acceptance. Candidate bodies remain bound to their original trials;
no model, host run, grading, or candidate rewrite occurs here.
