# Completion freezes 12 and 13

This directory retains the integration and regression freeze 12 and freeze 13 files
as exact byte copies, with the unchanged runner and dependency files from
[runner-snapshot-08](../runner-snapshot-08/snapshot.json).
[Snapshot metadata](snapshot.json) records hashes, modes, distinct candidate
identities and checks against unchanged raw cases, prompts, rubrics and fixtures.

Freeze 12 records the infrastructure completion report change. Freeze 13 retains
the later overload completion report change separately. Neither replaces earlier
results or grants acceptance. Candidate bodies remain bound to original trials;
no model, host run, grading or candidate rewrite occurs here.
