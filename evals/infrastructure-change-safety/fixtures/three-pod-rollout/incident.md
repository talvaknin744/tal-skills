An 18-hour import runs on three pods A/B/C, one owner at a time. Input is immutable; pages can replay safely under stable job_id. Progress is durable outside pods. Queue fail() or lease loss increments failure_count; count 3 dead-letters. Queue defer() releases safely checkpointed work without increasing that count. A rollout terminates A, then B, then C after each replacement is healthy. Each SIGTERM becomes TaskCancelled -> fail(). Counts become 1,2,3 and the job dies. Grace is 90 seconds. The queue polls independently from HTTP readiness. A PDB exists. Malformed input must still exhaust the three-failure policy. Lease renewal continues while a handler runs.
