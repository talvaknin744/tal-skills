# Benchmark report
Production traffic is described as independent client arrivals, with a target peak of 1000 requests/s. The test instead runs 80 virtual users; each sends one request and starts its next iteration only after the preceding response. Each iteration contains exactly one request, with no sleep or retry.
At a light configuration, mean iteration duration is 100 ms and completed throughput is 800 requests/s. With the expensive feature enabled, mean iteration duration is 1000 ms and completed throughput is 80 requests/s. All completed responses in both runs are HTTP 200 and have the expected content. The report calls the second run a passing 1000 requests/s capacity test because there are no errors.
Generator utilization, dropped starts, pending work, and latency of unfinished requests were not recorded. Dataset size is 100 rows versus 10 million in production; all requests address the same cached entity. The production request mix includes writes and uncached reads.
