# overload-control evaluation cases

These authored fixtures are synthetic project evidence, not measured production
results. Follow the [evaluation procedure](../README.md): isolate one fixture,
expose the candidate skill and capabilities, and keep this guide and cases.json
outside the executing agent's context. For a nontrigger case, expose normal
discovery metadata without explicitly activating the skill.

The corpus covers two substantive decisions and one scope boundary. All cases
are read-only and need no service or network. Record the answer, observable tool
trace, candidate identity and workspace diff; score the separate rubric.
A corpus-integrity check verifies packaging and isolation, not agent behavior.
