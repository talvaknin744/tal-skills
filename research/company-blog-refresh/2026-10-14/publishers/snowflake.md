## Reading and recommendations

### semantic-metrics-quality

Give data tools a semantic specification for measures, dimensions, relations, filters and business synonyms. For many models, prune representations, retrieve likely models, then choose among them. Validate source selection separately from SQL correctness and answer grounding, while enforcing the caller access boundary.

[Primary article](https://www.snowflake.com/en/blog/engineering/cortex-agents-unified-data-intelligence/). Complete main prose, shown semantic YAML, routing stages and governance section through Conclusion. Diagram pixels, linked current SDK and runtime were not verified.

The April 2025 preview status is historical. Current SDK behavior and security guarantees require current documentation and an executed target.

Proposed discriminating evaluation cases:

- The right metric exists in a domain with an ambiguous synonym.
- Top candidate retrieval misses the required model.
- A caller cannot access a selected data source.
- A small fixed API tool requires no semantic model router.

### stream-processing-design

Measure freshness through queryable and suitably organized data, rather than ending the clock at request acceptance. Model preclustering or minibatch delay as an explicit tradeoff against read cost, and include client transport, buffering and cross-zone costs in the experiment.

[Primary article](https://www.snowflake.com/en/blog/engineering/next-gen-snowpipe-streaming-architecture/). Complete main prose through Get started, architecture stages, comparison results and benchmark qualification. Diagram pixels and runtime were not verified.

The architecture report is not a durability proof. Its TPC derived results are explicitly unofficial and not certified.

Proposed discriminating evaluation cases:

- Fast request acceptance hides delayed query visibility.
- Preclustering improves query cost while breaching the freshness objective.
- A static batch export does not require continuous ingestion advice.
