# Sources and applicability

Reviewed 2026-09-29. Use the documentation for the installed versions. These are original engineering instructions derived from the sources, not reproduced book text.

- [TypeScript narrowing](https://www.typescriptlang.org/docs/handbook/2/narrowing.html) and [everyday types](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html): runtime checks establish narrowed values; assertions add no runtime validation.
- [Node TypeScript execution](https://nodejs.org/api/typescript.html): executing TypeScript by stripping types is separate from typechecking.
- [Node AbortSignal](https://nodejs.org/api/globals.html#class-abortsignal): supported API cancellation, already-aborted signals, and listener lifetime.
- [node-postgres transaction usage](https://node-postgres.com/features/transactions) and [pool API](https://node-postgres.com/apis/pool): one client per transaction, lease ownership, pool acquisition and shutdown.
- [pg 8.23.0 query configuration](https://github.com/brianc/node-postgres/blob/df274d1ba9ad9d11a8f1079314faeafde7208207/packages/pg/lib/query.js#L8-L28) and [client timeout implementation](https://github.com/brianc/node-postgres/blob/df274d1ba9ad9d11a8f1079314faeafde7208207/packages/pg/lib/client.js#L702-L731): absence of query AbortSignal support and nonpipeline timeout behavior. Pipeline mode differs.
- [pg connection termination](https://github.com/brianc/node-postgres/blob/df274d1ba9ad9d11a8f1079314faeafde7208207/packages/pg/lib/client.js#L203-L228) and [checkout listener transfer](https://github.com/brianc/node-postgres/blob/544b1ce8152bc280e398dc1e8a66920abe6a640e/packages/pg-pool/index.js#L335-L344): checked-out client connection errors need an owned listener in addition to an awaited query.
- [pg-pool 3.14.0 acquire queue](https://github.com/brianc/node-postgres/blob/544b1ce8152bc280e398dc1e8a66920abe6a640e/packages/pg-pool/index.js#L190-L235) and [retirement completion](https://github.com/brianc/node-postgres/blob/544b1ce8152bc280e398dc1e8a66920abe6a640e/packages/pg-pool/index.js#L172-L187): finite acquire timeout and removal after client end.
- [Node socket destruction](https://nodejs.org/api/net.html#socketdestroyerror) and [pg stream construction](https://github.com/brianc/node-postgres/blob/df274d1ba9ad9d11a8f1079314faeafde7208207/packages/pg/lib/connection.js#L13-L25): explicit transport ownership can force-close a stalled graceful retirement while its completion remains awaited.
- [PostgreSQL cancellation](https://www.postgresql.org/docs/current/libpq-cancel.html), [Read Committed](https://www.postgresql.org/docs/current/transaction-iso.html#XACT-READ-COMMITTED), and [statement timeout](https://www.postgresql.org/docs/current/runtime-config-client.html#GUC-STATEMENT-TIMEOUT): cancellation does not establish the command outcome; conflict arbitration can need a fresh statement snapshot; zero timeout disables the bound.
- [Effective TypeScript, second edition](https://effectivetypescript.com/): a candidate reading path for type design and boundaries. This skill does not claim full-book access or derive unverified chapter-specific advice from it.

Applicability limits: local PostgreSQL transactions do not make an external message or charge atomic; these driver findings do not establish behavior in another client, pipeline mode, a failover, or an untested version. The associated research used Node 25.9.0, PostgreSQL 18.6, a size-one pool, and synthetic loopback fixtures.
