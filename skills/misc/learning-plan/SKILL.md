# Learning plan

Turn the goal into observable performance and a feasible next session. Preserve the user's course, tools, deadlines and existing commitments.

## Workflow

1. **Establish the baseline.** Reuse known target, assessment rules, materials, actual progress and availability. Ask only for missing information that changes the route. Mark unverified dates or requirements as assumptions. A passed calendar date is not completed study. Done when the goal, remaining capacity and unknowns are explicit.
2. **Map performance.** List required skills and prerequisite blockers. Separate recalling conditions, choosing a method, executing it, explaining or proving it, and performing under assessment conditions. Sample relevant prior work or propose a short diagnostic; self-ratings alone leave readiness unknown. If starting that diagnostic in chat, present only its first question and wait for an attempt before revealing feedback or solutions. Done when each required area has observed evidence or an explicit unsampled status.
3. **Allocate capacity.** Count instruction, independent practice, feedback, cumulative retrieval, setup, breaks and logging inside the same time budget. Allocate first to consequential recurring gaps and prerequisites, while keeping coverage of required topics visible. Reserve assessment rehearsal and its correction time. State what is deferred when capacity is insufficient. Done when the allocations sum to available time and each appointment has a concrete output.
4. **Choose the next session.** Start with one target, a permitted source, a suitable task and a check of success. Supply a worked or faded example when prerequisites prevent a useful attempt; move toward independent varied problems. Keep method experiments small near a deadline. Done when the student can start without another planning session.
5. **Replan from evidence.** Update actual progress after attempts, preserving unfinished work. Compare independent correctness, assistance and elapsed time separately. Change a small part of the route when evidence supports it; avoid silently replenishing the original time budget. Finish with the revised allocation, next action and unresolved constraints.

## Conditional references

- For proof-heavy mathematics courses (real analysis, linear algebra), read [mathematics planning](references/mathematics.md) before selecting practice or reserved papers.
- For a timetable example, short-session fallback or lifelong-learning project, read [session patterns](references/session-patterns.md). These are adjustable templates.
- When explaining why a method was selected, read [evidence boundaries](references/evidence.md). Attribute coaching advice separately from research findings and local design decisions.

## Output

Give a compact plan with target, confirmed constraints, required skill coverage, allocations, assessment/repair checkpoints and the next action. Label unknown readiness rather than forecasting a grade. Scheduling reminders is a separate external action: a written plan is not an activated automation.
