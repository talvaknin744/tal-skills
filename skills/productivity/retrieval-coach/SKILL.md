# Retrieval coach

Build evidence of independent use through an attempt, feedback, repair and a later fresh check. Reading a solution and reproducing it immediately are useful instruction, but different evidence.

## Session loop

1. **Select one task.** Reuse the visible learning state, topic, available time and intended use. If history is absent, say so and obtain the last studied topic or use an agreed baseline. Resume an unanswered item before adding another queue. Read [review state](references/review-state.md) when a queue exists or scheduling a return. Done when the task fits the skill and time available.
2. **Protect the attempt.** Check the question's answer against reliable material before asking it. Present only the first question, without an answer or revealing hint, then wait. Ask for reasoning and optional pre-feedback confidence. Clearly label newly authored questions. If the learner requests instruction or a full solution, provide it and record exposure. Done when there is an actual attempt or an explicit help request; silence remains unanswered.
3. **Diagnose the evidence.** Check the reasoning, accept valid alternatives, and identify the first consequential gap. Separate observed error from a hypothesized cause. Record correctness, help and fresh/familiar exposure separately; confidence is not a score. If correctness is unresolved, mark it uncertain and seek a reliable check. Done when the feedback names a verified success or a specific gap with the uncertainty visible.
4. **Repair proportionately.** Ask one targeted question or offer one hint and wait. When prerequisites block progress, explain briefly or work an example, then fade support. Use the learner's existing description of the blockage instead of repeating an intake questionnaire. Done when the learner repairs the step or the next instruction needed is clear.
5. **Check transfer and retain state.** After assistance, choose a materially different problem for an independent check. Distinguish variation at comparable difficulty from increasing difficulty. Save only observed updates and the next due target using [review state](references/review-state.md). A session may end with an unresolved gap; label it accurately.

Keep an ordinary short recall session to the agreed time, often one to three tasks in fifteen minutes. A proof may use the entire session. Increase support when effort produces no useful progress; high strain is not a mastery measure.

## Conditional references

- For calculus, proofs or Hebrew prompts, read [mathematics coaching](references/mathematics.md) before asking the question.
- For a recurring reminder prompt, read [scheduled recall](references/scheduled-recall.md). Authoring a prompt does not create a schedule.
- When explaining method selection or a memory claim, read [evidence boundaries](references/evidence.md).

## Completion

During interaction, end at the next learner response point. At session close, show the demonstrated skill, remaining gap, assistance and next check in a compact state update. Readiness claims stay limited to skills and conditions actually tested.
